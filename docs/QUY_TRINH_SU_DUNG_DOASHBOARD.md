# Cách Sử Dụng Dashboard

---

## Đăng nhập

1. Mở link Dashboard
2. Nhập email + mật khẩu → nhấn **Đăng nhập**
3. Chưa có tài khoản → nhắn admin tạo

---

## Xem điểm

1. Sidebar → chọn **Overview** (Video Creative hoặc Graphic Design)
2. Chọn khoảng thời gian ở thanh filter trên cùng (Tuần này / 7 ngày / 14 ngày / theo tháng / custom)
3. Xem điểm, số task, % đạt target ở các ô KPI phía trên
4. Kéo xuống xem bảng task chi tiết

---

## Xem target

1. Sidebar → **Mục tiêu Target**
2. Chọn tháng muốn xem
3. Ô xanh = đạt, ô đỏ = chưa đạt
4. Số hiện dạng `điểm thực tế / target`

---

## Đăng ký ngày nghỉ

1. Sidebar → **Ngày Nghỉ**
2. Click vào ngày muốn nghỉ trên lịch
3. Chọn **Cả ngày** hoặc **Nửa ngày**
4. Ghi lý do (tuỳ) → nhấn **Thêm**
5. Muốn xoá → nhấn icon 🗑️

---

## Xem lịch sử due date

1. Sidebar → **Lịch sử Due Date**
2. Mũi tên đỏ = trễ deadline, mũi tên xanh = sớm hơn

---

## Tạo task trên Asana

1. Tạo task, đặt tên rõ ràng
2. Chọn **Assignee** = tên bạn
3. Set **Due Date**
4. Chọn **Video Type** (S1, S2A, S3B...) hoặc **Asset** (ScreenShot, Icon...)
5. Nhập **Video Count** / **Image Count**
6. Xong task → chuyển Progress = **Done** + kéo task vào section **"Done This Week"**

> Thiếu Video Type hoặc Count → không tính điểm.
> Không kéo vào Done This Week → không tính.

---

## Sync dữ liệu

- Hệ thống tự sync, không cần làm gì
- Muốn cập nhật ngay → nhấn **Sync Now** ở thanh filter

---

## Gặp lỗi

- Dashboard trống → nhấn **Sync Now**
- Điểm sai → kiểm tra Video Type + Count trên Asana
- Không thấy data → nhắn admin kiểm tra tên trong **Quản lý Users**
